Generate the survey key pair

Open this file on your own computer (double-click it). Nothing is uploaded: the keys are made inside your browser.

Public key (safe to publish)

Paste this into public/feedback/config.js as the value of PUBLIC_KEY.

Private key (secret)

Keep this file private. Anyone who has it can read every response. Do not put it in GitHub, email or chat. Store it in a password manager or on an encrypted drive. If you lose it, the responses cannot be recovered.
